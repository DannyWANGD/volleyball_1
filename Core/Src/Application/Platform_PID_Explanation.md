## 参数详细解释

### [0] PID基础参数组
- `kp`: 比例增益 (1.2/0.9/0.8)
- `ki`: 积分增益 (0.01)
- `kd`: 微分增益 (15.0/10.0/8.0)
- `sum_max`: 积分项最大值 (120.0)
- `output_max`: 输出限幅值 (40.0/14.0/10.0)

### [1] 微分滤波参数组
- `kd_fil_param`: 微分项滤波系数 (0.1)
- `delta_fil_param`: 未使用 (-1表示禁用)

### [2] 前馈参数组
- `kf_1`: 前馈增益1 (0表示禁用)
- `kf_2`: 前馈增益2 (0表示禁用)

### [3] 前馈滤波参数组
- `kf1_fil_param`: 前馈1滤波系数 (-1表示禁用)
- `kf2_fil_param`: 前馈2滤波系数 (-1表示禁用)

## 带前馈的PID控制原理

带前馈的PID控制器在传统PID基础上增加了前馈补偿环节：
1. **前馈控制**：通过`kf_1`和`kf_2`参数对系统输入进行直接补偿
2. **滤波处理**：使用`kf1_fil_param`和`kf2_fil_param`对前馈信号进行平滑处理
3. **组合输出**：PID输出 + 前馈补偿 = 最终控制量

前馈控制的优势：
- 对可测量的扰动进行快速补偿
- 改善系统动态响应速度
- 与PID反馈控制形成互补

## 什么是“带前馈”的 PID

- 标准 PID 仅基于误差 `e = ref - fdb` 形成控制量：
  - 输出 `u_PID = Kp*e + Ki*∫e + Kd*(de/dt)`，并配合积分限幅 `sum_max` 与输出限幅 `output_max` 做保护
  - 本项目的计算实现见 `Core/Src/Algorithm/alg_pid.c:151-227`
- 带前馈的 PID 在此基础上加入“与参考相关”的直接项，形成：
  - `u_total = u_PID + u_FF`
  - 其中前馈 `u_FF = kf_1 * ref + LPF(kf_2 * d(ref)/dt)`，对应代码：`Core/Src/Algorithm/alg_pid.c:182-184`（位置式 PID）；`Core/Src/Algorithm/alg_pid.c:217-221`（增量式 PID）
- 直观意义：
  - `kf_1` 让控制输出与目标本体直接相关，适合抵消与设定值相关的静态负载或偏置
  - `kf_2` 使用参考的变化率（速度）做前馈，能在目标突变时提前“助推”，减少纯反馈带来的相位滞后

## 与项目代码的映射关系

- 串级结构：角度环输出作为速度环参考，再由速度环产出力矩；宏位置：`Core/Src/Modules/module_platform.c:239-262`
- PID 初始化的参数来源于常量表（每档 fast/middle/slow 各一套），位置：`Core/Src/System/sys_const.c:35-57`
- 参考的一阶、二阶差分计算：`Core/Src/Algorithm/alg_pid.c:169-170`（注意：当前差分调用使用 `dt=1`）
- 输出与限幅：位置式 PID `Core/Src/Algorithm/alg_pid.c:182-185`，最终输出限幅 `Core/Src/Algorithm/alg_pid.c:223-227`

## 一级前馈与二级前馈的含义（结合当前实现）

- 一级前馈 `kf_1`
  - 直接乘参考值 `ref`，在代码中不再单独滤波（如需滤波可用 `kf1_fil_param`），适合消除与目标幅值相关的静态力矩需求
- 二级前馈 `kf_2`
  - 本项目当前实现为“参考的一阶导”前馈，即速度前馈：`LPF(kf_2 * ref_dError)`，其中 `ref_dError = d(ref)/dt`
  - 虽然代码也计算了 `ref_ddError`（参考加速度），但未参与输出；如需“加速度前馈”，需在 `u_FF` 中加入滤波后的 `ref_ddError` 项

## 为什么前馈能提升响应

- 反馈只能在“有误差”时产生作用，设定边沿到来时，误差与测量延迟导致相位滞后，响应变慢
- 前馈直接依据目标的已知变化推算所需控制量，减少对误差的依赖，缩短建立时间、降低滞后
- 速度前馈在目标突变时快速提供“起步力矩”，反馈负责修正细节与稳态精度，两者互补

## 调参方法与建议

- 顺序：先速度环，再角度环
  - 速度环的前馈更直接影响力矩与速度建立，角度环用于上层设定的边沿整形
- 从二级前馈（速度前馈）开始：
  - 在常量表中把速度环的 `kf_2` 设为小值（例如 `0.05~0.12`），并设置 `kf2_fil_param` 为中小值（如 `0.03~0.06`）以抑制噪声
  - 若上升太慢，逐步增加 `kf_2`；若抖动或噪声增大，增加 `kf2_fil_param` 或略减 `kp/kd`
- 再考虑一级前馈 `kf_1`：
  - 对存在与参考本体相关的静态负载（某些姿态下的电机支撑力）可引入 `kf_1`，初始值建议远小于 `kf_2`
- 角度环的前馈：
  - 用于改善上层设定值的边沿跟随，可将角度环 `kf_2` 设为 `0.10~0.18` 并配 `kf2_fil_param ≈ 0.05`
- 结合当前参数表的安全起点（fast 档示例）：
  - 俯仰速度环：`kf_2=0.08, kf2_fil_param=0.03, kf_1=0.00~0.05`
  - 偏航速度环：`kf_2=0.10, kf2_fil_param=0.04, kf_1=0.00~0.05`
  - 俯仰角度环：`kf_2=0.12~0.18, kf2_fil_param=0.05, kf_1=0.00~0.05`
  - 偏航角度环：`kf_2=0.10~0.15, kf2_fil_param=0.05, kf_1=0.00~0.05`

## 量纲与时间步长（关键注意）

- 差分函数 `Math_Differential(arr, order, dt)` 支持真实 `dt`：`Core/Src/Algorithm/alg_math.c:86-97`
- 目前 PID 内调用使用 `dt=1` 周期单位，这使得 `kf_2` 的量纲表现为“每周期增量”，调参时数值应偏小
- 若未来改为真实 `dt`（例如传入 `Platform->update_dt`），`kf_2` 需要重新缩放至物理量纲一致；同时 `kd` 的有效强度也会变化

## 加速度前馈的扩展（当前未启用）

- 代码已计算 `ref_ddError`（参考加速度）：`Core/Src/Algorithm/alg_pid.c:170`
- 如需引入加速度前馈，可将 `u_FF` 扩展为：`u_FF = kf_1*ref + LPF(kf_2*d(ref)/dt) + LPF(kf_3*d^2(ref)/dt^2)`
- 引入后需：
  - 使用真实 `dt` 计算差分
  - 为 `kf_3` 配合合理滤波参数，避免噪声放大
  - 重新联调 `kp/kd`，防止高频增益过大导致抖动

## 常见问题与对策

- 超调增大：减小 `kf_2` 或增加 `kf2_fil_param`，并略减速度环 `kp`
- 高频抖动/噪声：增大前馈滤波参数；提高编码器滤波；适度减小 `kd` 或加大 `kd_fil_param`
- 稳态偏差：在允许范围内增加 `ki`，或适当引入小量 `kf_1`
- 响应仍有限：检查输出节流与力矩限幅（`Core/Src/Modules/module_platform.c:786-817, 216-227`），在硬件允许下适度降低组间延时或提高限幅
